DELHI URBAN HEAT INTELLIGENCE

Project Description

This project analyses urban heat patterns in Delhi using GIS, Remote Sensing and Python.

Objectives

- Analyse NDVI (Vegetation Index).
- Study UHI (Urban Heat Island).
- Analyse LST (Land Surface Temperature).
- Identify high-temperature areas.

Tools Used

- QGIS
- Python
- VS Code
- Microsoft Excel
- Remote Sensing

Project Structure

- data/processed – Processed raster statistics.
- models – Analysis and model files.
- results – Final project report and outputs.
- urban_heat_intelligence.py – Python analysis script.

Conclusion

The project helps understand the relationship between vegetation, land surface temperature and urban heat in Delhi.
