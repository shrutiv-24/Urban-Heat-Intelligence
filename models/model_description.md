Model Description

Project: Delhi Urban Heat Intelligence

This project uses GIS, Remote Sensing and Python for urban heat analysis.

Techniques Used

- NDVI (Normalized Difference Vegetation Index)
- LST (Land Surface Temperature)
- UHI (Urban Heat Island) analysis
- Statistical analysis of raster data

Libraries Used

- Python
- NumPy
- Pandas
- Rasterio
- Matplotlib
- GeoPandas

Purpose

To identify urban heat patterns in Delhi and understand the relationship between vegetation and land surface temperature.
